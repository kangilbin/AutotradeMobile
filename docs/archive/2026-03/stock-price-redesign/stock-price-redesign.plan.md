# Plan: stock-price-redesign

## 1. 개요

| 항목 | 내용 |
|------|------|
| **Feature** | stock-price-redesign |
| **목표** | 주식 호가 화면(`price.tsx`)의 UI/UX를 앱 전체 디자인 테마(`theme.ts`)에 맞춰 트렌디하게 리디자인 |
| **대상 파일** | `app/(tabs)/stock/price.tsx`, `components/OrderBookRow.tsx` |
| **우선순위** | High |
| **작성일** | 2026-03-19 |

## 2. 현재 문제점

### 2.1 테마 불일치
- `price.tsx`에서 하드코딩된 색상 사용 (`#f9f9f9`, `#4CAF50`, `#9E9E9E`, `#939393` 등)
- 앱 공통 테마(`constants/theme.ts`)의 `Colors`, `Shadows`, `Spacing`, `BorderRadius` 미사용
- 다른 화면(홈, 스윙)과 시각적 통일감 없음

### 2.2 레이아웃/UX 문제
- **상단 헤더**: 검색 영역이 단순하고 종목 정보가 부족 (현재가, 등락률 미표시)
- **상태 바**: 단순 텍스트 바 (`정규장 실시간` / `정규장 종료`) — 시각적 임팩트 없음
- **호가 영역**: 매도/매수 호가와 부가정보(현재가, 기준가 등)의 레이아웃이 좁고 가독성 떨어짐
- **부가정보 패널**: `additionalContainer`의 padding/spacing이 너무 좁아 텍스트가 빽빽함
- **FAB 버튼**: 위치와 색상은 적절하나 테마 변수 미사용

### 2.3 OrderBookRow 컴포넌트
- 호가 행의 게이지 바 색상이 테마와 맞지 않음 (`#d8e7fc`, `#fce1e1` → `Colors.loss`, `Colors.profit` 계열로 변경 필요)
- 현재가 하이라이트 스타일이 임의 색상 사용

## 3. 리디자인 요구사항

### 3.1 테마 통일 (Must)
- [ ] 모든 하드코딩된 색상을 `Colors.*`로 교체
- [ ] `Shadows.*`, `Spacing.*`, `BorderRadius.*`, `FontSizes.*` 적용
- [ ] 매도 색상 → `Colors.loss` (#3498DB 파랑 계열), 매수 색상 → `Colors.profit` (#FF6B6B 빨강 계열)

### 3.2 상단 종목 정보 영역 (Should)
- [ ] 종목명 + 종목코드를 크게 표시
- [ ] 현재가, 전일 대비 등락금액/등락률을 상단에 바로 표시
- [ ] 장 상태 표시를 뱃지 형태로 변경 (녹색 점 + 텍스트)
- [ ] 뒤로가기 아이콘을 명확하게 배치

### 3.3 호가 테이블 리디자인 (Must)
- [ ] 매도 10호가 (상단) + 매수 10호가 (하단)을 세로 연속 배치로 변경
- [ ] 각 행: `[잔량 게이지 | 잔량 | 가격 | 등락률]` 형식
- [ ] 현재가 위치에 하이라이트 표시 (민트색 배경 or 굵은 테두리)
- [ ] 게이지 바: 매도는 파랑(`Colors.loss` 계열), 매수는 빨강(`Colors.profit` 계열)
- [ ] 가격 텍스트에 상승/하락/보합 색상 적용

### 3.4 부가 정보 카드 (Should)
- [ ] 현재가, 기준가, 시가, 고가, 저가를 별도 카드 영역으로 분리
- [ ] 카드 스타일: `Colors.cardBackground` + `Shadows.small` + `BorderRadius.md`
- [ ] 예상체결가/예상대비를 하단 별도 섹션으로 배치

### 3.5 FAB 버튼 (Nice to have)
- [ ] `Colors.primaryLight` 사용
- [ ] `Shadows.large` 적용

## 6. 구현 순서

1. **Phase 1**: `price.tsx` 하드코딩 색상 → 테마 변수 교체
2. **Phase 2**: 상단 종목 정보 영역 리디자인 (현재가, 등락률 표시)
3. **Phase 3**: 호가 테이블 세로 배치로 레이아웃 변경
4. **Phase 4**: `OrderBookRow.tsx` 테마 적용 및 게이지 스타일 개선
5. **Phase 5**: 부가 정보 카드 영역 리디자인
6. **Phase 6**: FAB 및 하단 정보 스타일 정리

## 7. 기술 참고사항

- 테마 import: `import { Colors, Shadows, Spacing, BorderRadius, FontSizes } from '../../../constants/theme';`
- 수익/손실 색상 규칙: 가격 > 기준가 → `Colors.profit` (빨강), 가격 < 기준가 → `Colors.loss` (파랑), 보합 → `Colors.textSecondary`
- FlatList 유지 (성능 최적화), 가상 스크롤 활용
- `useCallback`, `useMemo` 메모이제이션 기존 패턴 유지
