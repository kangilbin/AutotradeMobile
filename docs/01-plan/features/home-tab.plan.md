# Plan: home-tab (v2 — 미국장 등락률 랭킹 지원)

> 홈 탭 순위 화면에 미국 주식 등락률 랭킹 추가

## 1. 개요

기존 홈 탭은 국내장(J) 등락률/거래량/체결강도 3종 순위를 보여준다.
이번 업데이트로 미국장(NASD)의 **등락률 순위**를 동일한 UI로 표시한다.

핵심 문제: 국내장과 미국장의 API 응답 데이터 구조가 완전히 다름.

## 2. 범위

### 포함
- 미국장 등락률 API 응답을 국내장 형태로 정규화 (Normalizer)
- 기존 컴포넌트의 가격 포맷을 마켓별 분기 (원 → $)
- 미국장일 때 등락률 탭만 활성화 (거래량/체결강도 API 없음)
- 필터 칩을 미국장에 맞게 조정

### 제외
- 미국장 거래량/체결강도 순위 (API 미존재)
- 종목 상세 페이지 미국장 연동 (별도 feature)

## 3. 데이터 매핑

| 역할 | 국내장 (FluctuationRankItem) | 미국장 (API 원본) |
|------|------------------------------|-------------------|
| 종목코드 | `stck_shrn_iscd` | `symb` |
| 순위 | `data_rank` | 배열 인덱스+1 |
| 종목명 | `hts_kor_isnm` | `knam` |
| 현재가 | `stck_prpr` (정수/원) | `last` (소수/달러) |
| 전일대비 | `prdy_vrss` | `diff` |
| 등락부호 | `prdy_vrss_sign` | `sign` |
| 등락률 | `prdy_ctrt` | `rate` (부호 포함) |
| 거래량 | `acml_vol` | `tvol` |

## 4. 핵심 결정사항

- **Normalizer 패턴**: 미국장 응답을 `FluctuationRankItem`으로 변환하여 기존 UI 재활용
- **가격 포맷**: `utils/format.ts`의 `formatPrice(price, mrktCode)` 활용 (이미 존재)
- **탭 제한**: 미국장 선택 시 등락률 탭만 활성화, 나머지 탭 비활성화
