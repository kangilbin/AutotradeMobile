# Plan: 스윙 등록 화면 해외 주식 대응 (add-screen)

## 개요

스윙 등록 화면(`app/(tabs)/stock/add.tsx`)이 현재 국내 주식 전용으로 되어 있어, 미국 주식 등록 시에도 금액이 원화(₩)로만 표시된다. 마켓 코드(`mrktCode`)에 따라 통화 단위, 금액 프리셋, 포맷팅을 분기하여 해외 주식도 올바르게 지원하도록 개선한다.

## 현재 문제점

| 항목 | 현재 상태 | 문제 |
|------|-----------|------|
| 금액 단위 | `원` 하드코딩 (line 322) | 미국 주식도 "원"으로 표시 |
| 금액 프리셋 | 100만/500만/1000만 고정 | 달러 기준 프리셋 없음 |
| 금액 입력 포맷 | `toLocaleString()` (정수) | 달러는 소수점 2자리 필요 |
| 서브 텍스트 | "스윙 매매 설정" 고정 | 마켓 구분 없음 |

## 변경 범위

### 1. 통화 단위 분기
- `mrktCode === 'NASD'` → `$` 표시, 아닐 경우 → `원` 표시
- 기존 `getCurrencySymbol()`, `formatAmountWithUnit()` 유틸 활용

### 2. 금액 프리셋 마켓별 분기
- **국내(J)**: 100만 / 500만 / 1000만 (기존 유지)
- **미국(NASD)**: $1,000 / $5,000 / $10,000

### 3. 금액 입력 포맷 분기
- **국내**: 정수, 천단위 구분자 (1,000,000)
- **미국**: 소수점 2자리 허용 ($1,000.00)

### 4. 스톡 헤더 마켓 표시
- 마켓 플래그/라벨 표시 (선택사항)

## 영향 파일

| 파일 | 변경 내용 |
|------|-----------|
| `app/(tabs)/stock/add.tsx` | 통화 단위, 프리셋, 포맷 분기 |
| `utils/format.ts` | 기존 유틸 활용 (변경 없을 수 있음) |
| `types/market.ts` | 기존 타입 활용 (변경 없음) |

## 기존 인프라 활용

이미 프로젝트에 마켓별 통화 처리 인프라가 완비되어 있음:
- `MarketCode` 타입 (`'J' | 'NASD'`)
- `useMarketStore` (현재 선택된 마켓)
- `formatPrice()`, `formatAmountWithUnit()`, `getCurrencySymbol()` 유틸
- `MARKETS` 상수 (label, flag, currency, currencySymbol)
- `mrktCode` 파라미터가 이미 `useLocalSearchParams()`로 전달됨

## 구현 우선순위

1. **P0**: 통화 단위 분기 (원 → $ / 원)
2. **P0**: 금액 프리셋 마켓별 분기
3. **P1**: 금액 입력 포맷 분기 (소수점 허용)
4. **P2**: 스톡 헤더에 마켓 표시
